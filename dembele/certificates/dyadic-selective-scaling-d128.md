is a prospective byte inventory, not an already enforced cap. New code
must reserve the complete declared output size while holding the write
lock, write only one serialized row at a time, synchronize and verify the
final length, and retain D127's journal-before-retirement protocol. Old
frozen artifacts and sealed scratch namespaces must remain untouched.
Permanent receipts and phase metadata remain outside scratch.

At the final checkpoint the four state payloads would total 558,829,536
bytes; the direct CM binary would add 43,520,000. CM output must be split
by chart if its measured work approaches the job cap. The full conditional
P=10552 solve still needs its own complete resource analysis.

Decision: proceed to one actual P=1600-to-P=3200 column using a new
integrated driver, starting from retained column 0. Use selective serial
processing, initially six-state chunks, and the existing P=1600 factor through
D127's exact residual lift. Split correction RHS construction from the
low solve/state update so a complete RHS sweep cannot overrun the serial
job cap. Preserve full original GMP reconstruction and verification,
old overlaps, exact masses, direct CM and independent audits. The source
numbers begin at 528. These sample timings do not establish the
affordability of a larger full bank; the original resource pauses remain.
